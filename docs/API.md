# HTTP API

Базовый адрес при запуске по умолчанию: `http://127.0.0.1:8000`.
На занятом порту: `APP_PORT=8011 make run` и `http://127.0.0.1:8011`.
Адрес Linux-стенда: `http://172.16.114.10:8000`.
API справочников доступен только после входа. Используется cookie-сессия.

| Метод | Путь | Результат |
|---|---|---|
| GET | `/` | HTML-интерфейс |
| GET | `/health` | 200 `{"status":"ok","database":"ok"}`, проверка четырёх таблиц; при ошибке БД 503 |
| GET | `/api/{resource}` | 200, массив объектов, сортировка по ID |
| GET | `/api/{resource}/{id}` | 200, один объект; 404 если отсутствует |
| POST | `/api/{resource}` | 201, созданный объект, заголовок Location |
| PUT | `/api/{resource}/{id}` | 200, полностью обновлённый объект |
| DELETE | `/api/{resource}/{id}` | 204, без тела |

`resource` — только `buildings`, `departments`, `rooms`.
Пагинация, фильтры и PATCH в текущей версии не реализованы.
POST/PUT: `Content-Type: application/json`, все указанные поля обязательны,
неизвестные поля запрещены. ID назначается сервером и не передаётся в теле.

## Тела POST и PUT

Корпус:

```json
{"name":"Главный корпус","address":"Учебная улица, 1"}
```

Подразделение:

```json
{"name":"Кафедра информатики"}
```

Помещение (`building_id` и `department_id` соответствуют существующим записям):

```json
{"building_id":1,"department_id":1,"number":"101","area":40.5,"height":3.2}
```

Ответ помещения:

```json
{"id":1,"building_id":1,"department_id":1,"number":"101","area":40.5,"height":3.2,"volume":129.6}
```

Названия: 1–100 символов, адрес: 1–250, номер: 1–30, крайние пробелы удаляются.
ID родителей — положительные JSON integers в диапазоне SQLite (до 2^63−1).
Числовые строки и boolean не принимаются за числа.
Площадь (м²): 0 < area ≤ 100000; высота (м): 0 < height ≤ 100;
NaN и Infinity недопустимы. Объём вычисляется, передавать его нельзя.

## Ошибки

Формат: `{"error":"Понятное описание причины"}`.

| Код | Причина |
|---|---|
| 400 | Невалидный JSON, неверные поля, типы, пустые строки, выход за диапазоны |
| 401 | Требуется вход или неверный логин/пароль |
| 403 | Отсутствует или неверен CSRF-токен |
| 500 | Неожиданная ошибка сервера, подробности только в журнале |
| 404 | Неизвестный ресурс, адрес или отсутствующая запись |
| 405 | Неподдерживаемый метод; допустимые указаны в Allow |
| 409 | Дубликат имени/номера, отсутствующий родитель, удаление используемого родителя |
| 413 | Тело запроса больше 16 КиБ |
| 415 | POST/PUT без JSON Content-Type |
| 503 | Ошибка чтения/записи БД, в том числе блокировка |

При ошибке изменения уже существующая запись остаётся прежней.

## Вход и сессия

- `GET /login` — HTML-форма; `POST /login` — поля формы `username`, `password`,
  `csrf_token`. После успеха — перенаправление на `/`, неверный пароль — 401.
- `GET /api/auth/session` — публичный адрес: `{"user":null,"csrf_token":"..."}`
  либо пользователь с `id` и `username`. Сохраните cookie ответа.
- `POST /api/auth/login` — JSON ровно с `username` и `password`, заголовок
  `X-CSRF-Token` из предыдущего ответа и та же cookie. При успехе — 200,
  `{"user":{"id":1,"username":"operator"},"csrf_token":"новый токен"}`.
- `POST /api/auth/logout` — текущая cookie и токен; ответ 204.

Все POST/PUT/DELETE требуют заголовок `X-CSRF-Token` и cookie из одной сессии.
После входа токен меняется. Не передавайте пароль в URL. Для ручной проверки
используйте браузер: он передаёт токен автоматически. Пользователя создаёт
администратор командой `.venv/bin/flask --app campus create-user operator`.
Пароль вводится скрыто; открытой регистрации нет.

Cookie подписана `SECRET_KEY`, HttpOnly, SameSite=Lax, срок сессии — до 8 часов.
Secure включается окружением для HTTPS. Ответы с данными и авторизацией имеют
`Cache-Control: no-store`. `/health`, форма входа и статические файлы публичны.
`/` без сессии перенаправляет на `/login`, `/api/{resource}` возвращает JSON 401.

Пароли и хеши не возвращаются API. Логи не включают тела запросов и cookie.
У всех пользователей одинаковые права CRUD; отдельных ролей нет.

Простая проверка без входа:

```bash
curl -i http://127.0.0.1:8000/health
# 200
curl -i http://127.0.0.1:8000/api/rooms
# 401
```
