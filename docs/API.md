# HTTP API

Базовый адрес при запуске по умолчанию: `http://127.0.0.1:8000`.
На занятом порту: `APP_PORT=8011 make run` и `http://127.0.0.1:8011`.
Аутентификации нет; приложение предназначено для локального учебного использования.

| Метод | Путь | Результат |
|---|---|---|
| GET | `/` | HTML-интерфейс |
| GET | `/health` | 200 `{"status":"ok","database":"ok"}`, при ошибке БД 503 |
| GET | `/api/{resource}` | 200, массив объектов, сортировка по ID |
| GET | `/api/{resource}/{id}` | 200, один объект; 404 если отсутствует |
| POST | `/api/{resource}` | 201, созданный объект, заголовок Location |
| PUT | `/api/{resource}/{id}` | 200, полностью обновлённый объект |
| DELETE | `/api/{resource}/{id}` | 204, без тела |

`resource` — только `buildings`, `departments`, `rooms`.
Пагинация, фильтры, PATCH и авторизация не входят в контракт ЛР1.
POST/PUT: `Content-Type: application/json`, все указанные поля обязательны,
неизвестные поля запрещены. ID назначается сервером и не передаётся в теле.

## Тела POST и PUT

Корпус:
```json
{"name":"Главный корпус","address":"Учебная улица, 1"}
```

Подразделение:
```json
{"name":"Кафедра информатики"}
```

Помещение (подставьте реальные ID созданных родителей):
```json
{"building_id":1,"department_id":1,"number":"101","area":40.5,"height":3.2}
```

Ответ помещения:
```json
{"id":1,"building_id":1,"department_id":1,"number":"101","area":40.5,"height":3.2,"volume":129.6}
```

Названия: 1–100 символов, адрес: 1–250, номер: 1–30, крайние пробелы удаляются.
ID родителей — положительные JSON integers в диапазоне SQLite (до 2^63−1).
Числовые строки и boolean не принимаются за числа.
Площадь (м²): 0 < area ≤ 100000; высота (м): 0 < height ≤ 100;
NaN и Infinity недопустимы. Объём вычисляется, передавать его нельзя.

## Ошибки

Формат: `{"error":"Понятное описание причины"}`.

| Код | Причина |
|---|---|
| 400 | Невалидный JSON, неверные поля, типы, пустые строки, выход за диапазоны |
| 404 | Неизвестный ресурс, адрес или отсутствующая запись |
| 405 | Неподдерживаемый метод; допустимые указаны в Allow |
| 409 | Дубликат имени/номера, отсутствующий родитель, удаление используемого родителя |
| 413 | Тело запроса больше 16 КиБ |
| 415 | POST/PUT без JSON Content-Type |
| 503 | Ошибка чтения/записи БД, в том числе блокировка |

При ошибке изменения уже существующая запись остаётся прежней.

## Пример проверки curl

```bash
curl -i http://127.0.0.1:8011/health
curl -i -H 'Content-Type: application/json' \
  -d '{"name":"Корпус Б","address":"Учебная улица, 2"}' \
  http://127.0.0.1:8011/api/buildings
curl -i -H 'Content-Type: application/json' \
  -d '{"name":"Деканат"}' http://127.0.0.1:8011/api/departments
# Для помещения используйте ID из ответов выше.
curl -i http://127.0.0.1:8011/api/rooms
```
