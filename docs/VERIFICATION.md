# Результаты локальной проверки ЛР1

Дата: 17.09.2026. Окружение: macOS, Python 3.9.6 в `.venv`, Flask 3.1.3,
SQLite из стандартной библиотеки Python. Проверки выполнялись фактически.

## Автоматические проверки

- `make verify`: успешно, 41 тест; Ruff check, Ruff format --check и git diff --check проходят.
- `python -m pip check` внутри `.venv`: No broken requirements found.
- Проверка `node --check campus/static/app.js`: успешно. Node использован только
  для дополнительной проверки синтаксиса; для установки и запуска приложения не нужен.
- Чистый clone ветки `feature/lr1-campus` в `/tmp/lr1-clean-3Tu3wo/project`:
  Ruff, форматирование, pytest (41 тест), git diff --check проходят;
  `git status --short` пустой. Использовано уже установленное виртуальное окружение
  исходного проекта; повторная загрузка пакетов в новое окружение не проверялась.

Покрыты CRUD всех сущностей, вычисление и пересчёт объёма, уникальность номера
внутри корпуса и допустимость того же номера в другом корпусе, запрет удаления
используемых родителей, несуществующие ссылки, откат неуспешного изменения,
неверные типы и диапазоны, неизвестные поля, null, NaN/Infinity, слишком большой ID,
невалидный JSON, HTTP 400/404/405/409/413/415, read-only HEAD,
сохранение данных при повторном создании приложения, SQL-ограничения без API,
успех и отказ health-проверки. Тесты используют временные БД, не рабочую.

В ходе проверки исправлены две ошибки: переполнение SQLite INTEGER для ID в URL
и обработка HEAD как запроса с телом JSON. Регрессионные тесты сохранены.

## Реальный сервер и браузер

`APP_PORT=8011 make run` запускает приложение. Порт 8000 на машине занят.
Запрос `curl -i http://127.0.0.1:8011/health` возвращает HTTP 200 и
`{"database":"ok","status":"ok"}`. Доступ из песочницы к локальному сокету
ограничен; успешная HTTP-проверка выполнена вне этого ограничения.

В браузере проверены:

1. Пустой список и подсказка сначала создать корпус и подразделение.
2. Создание корпуса «Учебный корпус» и подразделения «Кафедра информатики».
3. Создание помещения 101, площадь 40.5, высота 3.2: объём 129.6.
4. Изменение площади на 50: объём 160.
5. Повтор номера 101 в том же корпусе: ошибка, дубликат не появился.
6. Попытка удалить используемый корпус: ошибка связи, корпус сохранён.
7. Удаление созданного помещения: успешное сообщение и пустой список.

В рабочей локальной БД остались демонстрационные корпус и подразделение;
помещение после проверки удалено. Эти данные не входят в Git.
При визуальном просмотре узкого окна таблице добавлена минимальная ширина
и горизонтальная прокрутка, чтобы названия не разбивались на отдельные буквы.
Отдельный полный прогон по нескольким браузерам и размерам экранов не выполнялся.
