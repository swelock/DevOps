# Результаты проверок

## Локальная версия — 17.09.2026

Окружение: macOS, Python 3.9.6, Flask 3.1.3, SQLite.
`make verify` завершился успешно: 41 тест, Ruff, проверка форматирования и diff.
Дополнительно выполнены `pip check`, `node --check campus/static/app.js`
и проверка чистого клона с использованием установленного виртуального окружения.

Через браузер проверены создание корпуса и подразделения, добавление помещения
40.5 м² × 3.2 м с объёмом 129.6 м³, изменение площади до 50 м² с объёмом 160 м³,
отказ при дубликате номера и удалении используемого корпуса, удаление помещения.
`/health` вернул HTTP 200. Проверка нескольких браузеров не проводилась.

## Linux-развёртывание — 26.09.2026

Локальный `make verify`: 43 теста, Ruff, форматирование, синтаксис deploy-скриптов,
поиск явных секретов и `git diff --check` — успешно.
Проверка конфигурации Gunicorn и smoke-тест с двумя рабочими процессами
на SQLite завершились успешно; `/health` вернул HTTP 200.

Стенд: VMware Fusion, две Ubuntu Server 24.04 ARM64.

| Узел | Адрес | Служба после перезагрузки |
|---|---|---|
| `campus-app` | `172.16.114.10/24` | `campus.service`: enabled, active |
| `campus-db` | `172.16.114.20/24` | `postgresql.service`: enabled, active |

Результаты проверки:

- SSH по ключу под `devopsadmin`; удалённый root-вход и парольный вход отключены.
- Gunicorn работает от `campusapp` и слушает порт 8000.
- PostgreSQL слушает loopback и адрес сервера БД. UFW допускает порт 5432 только
  от `172.16.114.10`; соединение с хоста VMware завершилось тайм-аутом.
- Создание корпуса, подразделения и помещения возвращает HTTP 201.
  Для площади 48.5 м² и высоты 3.2 м рассчитан объём 155.2 м³.
- После SIGKILL главного процесса Gunicorn служба восстановилась,
  PID изменился, счётчик `NRestarts` увеличился с 0 до 1.
- При остановке PostgreSQL `/health` вернул HTTP 503; после запуска — HTTP 200.
- После перезагрузки обеих VM сохранились адреса и данные, службы запустились
  автоматически.
