# LR1-01 Учёт аудиторного фонда

Тип: функция. Статус реализации: выполнена.
Ветка: `feature/lr1-campus`.
Это постановка задачи, сохранённая до начала реализации в коммите `00dbed4`.

## Задача

Сотрудник хозяйственной службы должен вести корпуса, подразделения и помещения
через браузер. Помещение принадлежит одному корпусу и одному подразделению,
имеет номер, площадь и высоту. Объём рассчитывается автоматически.

## Критерии приёмки

- CRUD для трёх сущностей в HTTP API и интерфейсе.
- Номер помещения уникален внутри корпуса, площадь и высота положительны.
- Корпус или подразделение с помещениями нельзя удалить.
- Некорректные данные дают понятные ошибки и не портят БД.
- Данные сохраняются при перезапуске; `/health` проверяет доступность БД.
- Настройки через окружение, `.env.example`, исключение локальных файлов из Git.
- Схема данных, описание API, правила приёмки и воспроизводимые проверки.

## Проверка

`make verify`, затем ручной CRUD в браузере и просмотр diff другим участником.
Проверка другим участником и удалённый PR обязательны перед приёмкой командой.
