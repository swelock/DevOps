## Что показать преподавателю

1. Тему и ТЗ: объяснить пользователей и ограничения локальной версии без авторизации.
2. `make verify` с успешным результатом.
3. Веб-интерфейс: создать корпус и подразделение, помещение 40.5 × 3.2 → 129.6 м³,
   изменить площадь, показать новый объём. Показать ошибку дубликата, затем запрет
   удаления используемого корпуса. Удалить помещение, затем освободившийся корпус.
4. `/health`, пример JSON API и `campus/schema.sql`: внешние ключи,
   `UNIQUE(building_id, number)`, ограничения и транзакции.
5. На GitHub/GitLab показать задачу → ветку → коммиты → review → PR/merge → тег.
6. `git log --graph --oneline --all` и `docs/CONFLICT.md` — обе стороны конфликта
   и результат объединения.
7. `CONTRIBUTING.md` и `git check-ignore -v .env instance/campus.sqlite3 .venv/bin/python`.
8. Выполнить контрольную небольшую правку через новую задачу, ветку и PR.

Подробные ручные команды: `docs/GIT-WORKFLOW.md`.
