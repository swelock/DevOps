# Учёт корпусов, подразделений и помещений для ЛР1

Задача: вставить ссылку на Issue, созданную из `docs/issues/LR1-01.md`.

Вместо пустого проекта реализован локальный справочник аудиторного фонда:
Flask API, SQLite и браузерные формы CRUD для трёх связанных сущностей.
Номер помещения уникален в корпусе, используемые справочники защищены от удаления,
объём вычисляется из площади и высоты. Некорректные запросы дают JSON-ошибки.

Добавлены ТЗ, схема данных, API, настройки через окружение, `/health`,
правила приёмки и описание настоящего разрешённого конфликта README.

Проверки автора: `make verify` — 41 тест, Ruff и форматирование проходят;
в браузере проверены создание, изменение, удаление помещения и ошибки связей/дубликата.
Точные результаты и ограничения: `docs/VERIFICATION.md`.

Отдельно проверить новые файлы приёмки: `Makefile`, `pyproject.toml`, `tests/`,
`requirements*.txt`, `.gitignore`, `CONTRIBUTING.md`. До этой функции их проверок
в проекте не существовало; они добавлены, а не ослаблены.

Рецензент: другой участник команды. Его review и решение о слиянии пока отсутствуют.
Локальный тег `v0.1.0` указывает на проверенный автором снимок; не публикуйте тег
до review. Используйте обычный merge с сохранением коммитов, чтобы тег оставался
на коммите, входящем в историю `main`.
