## Быстрый запуск

```bash
cd Project_DevOps
make setup
cp .env.example .env
make verify
make run
```

Открыть `http://127.0.0.1:8000`. Если порт занят: `APP_PORT=8011 make run`,
затем `http://127.0.0.1:8011`. Остановить: Ctrl+C.
`cp .env.example .env` нужен только при первой настройке, не перезаписывайте свои настройки.
Проверено на macOS, Python 3.9.6; код совместим с Python 3.9+.
`make setup` требует интернет для установки зависимостей.

Первый запуск создаёт пустую БД. В браузере сначала создайте корпус и подразделение,
затем помещение. При повторном запуске записи сохраняются.

## Настройки

`run.py` читает `.env` из корня проекта через python-dotenv.
Переменные процесса имеют приоритет над `.env`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| APP_HOST | 127.0.0.1 | Локальный адрес сервера |
| APP_PORT | 8000 | Порт HTTP, от 1 до 65535 |
| DATABASE_PATH | instance/campus.sqlite3 | Файл SQLite относительно корня проекта |

Сервер Flask используется для локальной учебной демонстрации. Авторизации нет;
не открывайте приложение в публичную сеть. Для ЛР1 не нужны Docker, CI/CD,
внешний сервер БД, Node.js или сборщик frontend.

## Проверки и структура

`make test` — тесты API/БД; `make quality` — Ruff и форматирование;
`make verify` — оба этапа и `git diff --check`; `make format` — форматирование Python.

- `campus/__init__.py` — Flask, API, валидация и транзакции.
- `campus/schema.sql` — три таблицы и ограничения SQLite.
- `campus/templates/`, `campus/static/` — HTML, CSS и JavaScript интерфейса.
- `run.py` — окружение и локальный запуск.
- `tests/test_app.py` — автоматические проверки, отдельные временные БД.
